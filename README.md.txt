# Victoria Road Safety Dashboard 🚦

This repository showcases an interactive Tableau dashboard analyzing road crashes across Victoria, Australia.  
The project demonstrates my ability to transform raw crash data into actionable insights for policy, planning, and public awareness.

## 📊 Dashboard Overview

**Tool:** Tableau  
**Data:** Victorian Road Crash Statistics
**Focus:** Identifying high‑risk groups, locations, and conditions

### Key Features
- **Who's at Risk:** Casualties by age group and road user type (drivers, passengers, pedestrians, cyclists, motorcyclists).
- **Crash Clusters:** Interactive map showing geographic hotspots across Victoria.
- **LGA Analysis:** Crash density by Local Government Area with drill‑down filters.
- **Weather & Time Heatmap:** Crash risk patterns by weather conditions and time of day.
- **Trends Over Time:** Longitudinal view of crashes by road user type.

## 🚀 How to View
1. Download the Tableau workbook `Victoria_Road_Safety_Dashboard`.
2. Open with Tableau Desktop or Tableau Public.
3. Explore the interactive dashboard.
